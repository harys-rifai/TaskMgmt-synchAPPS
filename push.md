# Push TaskMgmt-synchAPPS to GitHub

Run these commands from the project root (`C:\www\n8n`):

```bash
git remote add origin https://github.com/harys-rifai/TaskMgmt-synchAPPS.git
git branch -M main
git push -u origin main
```

## Prerequisites

```bash
git init
git add .
git commit -m "Initial commit"
```

## Push script

```bash
.\push.bat
```
